Alamza Scripts

Hosting the app on Firebase

Ye app ek single file hai — index.html. Isay Firebase Hosting pe daalne ke do tareeqe hain: browser se drag-and-drop (sab se aasaan), ya CLI se. Neeche dono hain, aur wo do console settings jo sign-in aur database ke liye lazmi hain.

Before you start

Project

alamza-scripts — already wired into the app.

File to deploy

index.html — self-contained, no build step.

Needed once

Google + Anonymous sign-in, and database rules.

Cost

Spark (free) plan is enough to start.

Route A — no tools

Deploy by drag-and-drop

1

Download index.html

Project se index.html download karein. Isay ek khali folder me rakhein — bas ye ek file kaafi hai.

2

Firebase Console → Hosting

Open console.firebase.google.com → alamza-scripts → Hosting, phir Get started dabayein aur CLI wale steps skip kar dein — sirf site ban jane dein.

3

Folder drop karein

Hosting page pe site ke saamne ⋯ → Manage site kholein. Wahan "Add another release" ka drop area hota hai — apna folder (jis me index.html hai) uspe drag kar dein. Deploy ho jayega.

4

Live URL

App https://alamza-scripts.web.app pe chalegi. Public share links isi domain se banenge, jaise https://alamza-scripts.web.app/#/s/AbC123.

Route B — recommended for updates

Deploy with the Firebase CLI

1

Install and sign in

# Node.js 18+ chahiye
npm install -g firebase-tools
firebase login
2

Folder banayein

Ek folder banayein, uske andar public/ aur us me index.html rakhein:

alamza-scripts-host/
├─ firebase.json
├─ database.rules.json
└─ public/
   └─ index.html
3

firebase.json

Ye file bana kar neeche wala content paste kar dein. Rewrite lazmi hai — share links hash pe chalte hain, magar deep refresh pe bhi index.html hi serve hona chahiye.

{
  "hosting": {
    "public": "public",
    "ignore": ["firebase.json", "**/.*"],
    "rewrites": [{ "source": "**", "destination": "/index.html" }],
    "headers": [{
      "source": "/index.html",
      "headers": [{ "key": "Cache-Control", "value": "no-cache, max-age=0" }]
    }]
  },
  "database": { "rules": "database.rules.json" }
}
4

Deploy

firebase use alamza-scripts
firebase deploy --only hosting,database

Aage jab bhi app update karein: naya index.html public/ me replace karein aur wahi command dobara chalayein.

Lazmi — warna sign-in aur sharing kaam nahi karenge

Console settings

1

Sign-in methods on karein

Authentication → Sign-in method me do provider enable karein:

  • Google — owner ke sign-in ke liye.
  • Anonymous — public link kholne walon ke liye (bina login "ready" tick kar sakein).
2

Authorized domains

Usi page pe Settings → Authorized domains me wo domain add karein jahan app chal rahi hai — alamza-scripts.web.app aur alamza-scripts.firebaseapp.com khud shaamil hote hain; custom domain ho to wo bhi add karein. Ye na ho to sign-in auth/unauthorized-domain deta hai.

3

Realtime Database rules

Realtime Database → Rules me project ki firebase-rules.json ka content paste kar ke Publish karein (ya CLI wale route me ye khud deploy ho jata hai). In rules ka matlab:

  • users/<uid> — sirf wohi user apna data padh/likh sakta hai.
  • pub/<token> — public share ka snapshot, sab padh sakte hain, likhna sirf sign-in walon ka.
  • done/<scriptId> — ready ticks, jaan boojh kar sab ke liye khuli hain (ek hi set sab ke liye).
  • grants/<email> — kis account ko kya share hua.

Database region: app alamza-scripts-default-rtdb.firebaseio.com use karti hai. Agar aap ka database kisi doosre region me bana hai (URL me asia-southeast1 waghera), to us URL ko app me update karna hoga.

Optional

Custom domain

Hosting → Add custom domain se apna domain jorein, Firebase jo TXT/A records de wo apne DNS me daal dein. SSL khud lag jata hai. Domain live hone ke baad usay Authorized domains me bhi add karna zaroori hai, warna Google sign-in block ho jayega. Share links phir naye domain se banenge — purane link bhi chalte rahenge jab tak purana domain live hai.

If something breaks

Quick checks

Sign-in popup band ho jata hai

Browser ne popup roka hai — is site ke liye popups allow karein.

auth/unauthorized-domain

Domain Authorized domains me nahi hai.

auth/operation-not-allowed

Google ya Anonymous provider enable nahi hua.

Share link khali khulta hai

Database rules publish nahi huin, ya share off kar diya gaya.

Purani app dikh rahi hai

Hard refresh karein — ya firebase.json ka no-cache header lagayein.

Scripts gayab

Bina sign-in ka data browser me hota hai; sign-in karne pe wo cloud pe chala jata hai.
